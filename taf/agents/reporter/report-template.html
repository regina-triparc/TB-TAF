Before you start

  • Work top to bottom. Mark each assertion Pass, Fail, Blocked or Unverified, and add a note for anything that isn't a clean pass.
  • Marks start from the automation run: a passed automated test pre-marks its assertions Pass; a failed one leaves them for you, with the error shown. Reset to automation restores those marks; Clear marks empties them.
  • Your marks and notes are saved in this browser only. When you're done, use Copy results and paste the table into Jira.
  • Never paste an error into Jira without reading it first: some error pages include a login token.
